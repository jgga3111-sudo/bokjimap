## 3. 가장 중요한 발견 — 네이버와 구글이 정반대다

같은 주제로 두 곳에서 검색해 봤다.

### 네이버 웹문서: 정부·공공기관이 독점

`에너지바우처 신청 대상 지원금액` 상위 10건 → **전부 .go.kr / .or.kr**

`청년월세 지원 신청 조건` 상위 12건 → **전부 정부·지자체**
(복지로, 국토교통부, 마이홈, 부산청년플랫폼, 서울주거포털, 인천청년포털…)

해피나눔도 지원금비서도 **개별 사업명 쿼리에서 한 건도 안 보인다.**
해피나눔이 1위를 잡은 건 `내가 받을 수 있는 지원금 찾기` 같은 **도구성 쿼리**뿐이다.

### 구글: 민간 콘텐츠가 상위에 올라온다

`청년월세 지원 2026 신청조건 소득기준` 상위 →
**brunch.co.kr(1위)**, 복지로, **토스뱅크**, 부산청년플랫폼, 서울주거포털,
**opcl.kr**, brunch

민간이 1위와 3위를 잡았다.

### 여기서 나오는 결론

**우리 전장은 구글이다.** 러닝온도 실적의 근거가 GSC 데이터였으니 일관된다.

## 4. 마라톤과 복지의 결정적 차이 (docs/02 보정)

docs/02에서 "러닝온의 `/races`처럼 개별 개체 페이지가 주력"이라고 결론 냈다.
그 방향은 유지하되, **전제 하나가 다르다는 걸 이번에 확인했다.**

| | 마라톤 대회 | 복지 사업 |
|---|---|---|
| 공식 페이지 | 없거나 부실 (소규모 주최) | **복지로에 100% 존재하고 충실** |
| 러닝온/복지맵의 역할 | 흩어진 것을 처음으로 모음 | 이미 모여 있는 것을 다시 모음 |
| 원문 그대로 옮기면 | 유일한 정보원 | **중복 콘텐츠** |

**상세 API 본문을 그대로 붙이는 것만으로는 복지로를 이길 수 없다.**
원문은 근거로 싣되, 그 위에 복지로에 없는 것을 얹어야 한다.

복지로에 없는 것:
- **조회수 순위** — 복지로는 인기순 정렬을 노출하지 않는다
- **가구원 수 × 소득 → 어느 기준선까지 열리는지 한 화면 판정**
  (복지로 모의계산은 사업별로 따로 들어가야 한다)
- **지역 페이지에 중앙부처 사업 병기** — 복지로는 축이 분리돼 있다
- 사업 간 비교·연결 (같은 대상의 다른 지원)

## 6. 2026-09-01 추가 발견 — 이름이 겹쳤다

도메인을 정하고 배포까지 마친 뒤에 알게 됐다. **이름을 정하기 전에 도메인과
상표를 먼저 조회했어야 했다.** 다음에 무엇을 만들든 이 순서를 지킨다.

### bokjimap.com — 이름이 같다

| | bokjimap.com | 우리(당시 bokjimap.co.kr) |
|---|---|---|
| 등록 | 2026-02-01 | 2026-08-31 |
| 서버 | Cloudflare | Vercel |
| 범위 | **서울시·자치구** 155개 | 전국 900건 |
| 사이트맵 | 698개 (정책 658) | 556개 |
| 애드센스 | **게재 중** (pub-1967967032171931) | 미신청 |

7개월 먼저 시작했고 `.com`을 갖고 있다. 사이트 구성에서 배울 점이 있다 —
`/glossary` 13개, `/guides` 10개, `/editorial-policy`, `/disclaimer`.
**원본 글 23편과 편집 방침**을 갖추고 애드센스를 통과했다. 정부 원문을
그대로 싣는 구조로도 승인이 난다는 실물 증거이자, 우리에게 무엇이
부족한지를 보여주는 목록이다.

### bokjinow.co.kr — 후보 이름을 쓰고 있었다

이름 후보로 "복지나우"를 검토하다 발견했다. `.com`(2026-04-27 등록)과
`.co.kr`을 모두 갖고 운영 중이다. 범위가 우리보다 훨씬 넓다 — 복지·부동산·
청년정책·서민금융·국고보조금·창업지원·농산물 시세까지. "정부24·LH·온통청년 등
공식 공공데이터 기반"이라고 밝히고 있고 쿠키 동의 배너가 있다.

### 그래서 이름을 바꿨다

**복지맵 → 복지클릭** (bokjimap.co.kr → bokjiclick.co.kr).

검색 순위로는 손해가 거의 없다 — 실수요는 브랜드명이 아니라 개별 사업명이다
(4절 데이터랩). 바꾼 이유는 **홍보**다. 카드뉴스를 본 사람이 "복지맵"을
검색하면 저쪽으로 간다. 색인 시작 전이고 백링크도 SNS 계정도 없는 지금이
가장 싸다.

이름을 정하기 전에 확인한 것:
- `bokjiclick` `.com`/`.co.kr` 둘 다 비어 있음 (RDAP·DNS)
- 키프리스 상표 "복지클릭" 0건, 어순을 바꾼 "클릭복지"도 0건
- 같은 이름의 서비스가 웹에 없음
- 정부 서비스와 혼동되지 않음 — **"복지지도"는 복지로의 공식 서비스명**이고
  "복지길"은 "복지로"와 한 글자 차이라 둘 다 뺐다

덤으로 알게 된 것: 상표 "복지맵"은 주식회사 비브로스가 출원했다가 **포기**해
살아있는 권리가 없다. 이름을 바꾼 건 법적 이유가 아니라 브랜드가 겹쳐서다.
